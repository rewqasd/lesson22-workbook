# Lesson 22 - A Glass Envelope | Interactive Workbook

A single self-contained HTML workbook for New Concept English Book 2, Lesson 22.

* One file, no external libraries or CDN: open it offline and every interaction still works.
* Tabs: Overview, Vocabulary, Grammar, Text & Story, Pronunciation, Practice Quizzes, Writing Lab.
* Practice Quizzes: multiple choice, true/false, fill in the blank, vocabulary matching, timeline ordering, sentence correction.
* Writing Lab: guided imitation writing.
* Progress is saved in the browser (localStorage).
